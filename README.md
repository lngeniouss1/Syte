# Дальше — сайт о путешествиях

Адаптивный сайт-каталог на Express и EJS: главная страница со слайдером, каталог направлений и контакты.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте <http://localhost:3000>. Для обычного запуска используйте `npm start`. Порт можно изменить переменной окружения `PORT`.

## Страницы

- `/` — главная и слайдер из трёх направлений.
- `/catalog` — страница каталога.
- `/contacts` — страница контактов.

На главной странице расположен слайдер из трёх фотографий. Страницы каталога и контактов пока содержат только заголовки. Фотографии загружаются с Unsplash.
