# Магазин — шаблон сайта

Простой адаптивный шаблон магазина на Express и EJS: главная страница со слайдером, каталог и контакты.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте <http://localhost:3000>. Для обычного запуска используйте `npm start`. Порт можно изменить переменной окружения `PORT`.

## Страницы

- `/` — главная и слайдер из трёх предложений.
- `/catalog` — страница каталога.
- `/contacts` — страница контактов.

На главной странице расположен слайдер из трёх фотографий магазина. Страницы каталога и контактов пока содержат только заголовки. Фотографии загружаются с Unsplash.
